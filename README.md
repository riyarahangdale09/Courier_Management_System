# Courier_Management_System

• Developed a full-stack courier platform with Spring Boot microservices, React (Vite) and MySQL, covering user
registration, courier booking, shipment tracking and profile management.
• Implemented JWT authentication and role-based access (User and Admin) with Spring Security; protected React routes
against unauthorized access.
• Built an admin module to manage users, couriers and delivery records.
• Documented APIs with Swagger (OpenAPI) and tested endpoints using Postman.
• Integrated a Python-based AI chatbot to answer customer queries.
• Maintained a detailed README covering project setup, architecture and API usage.
